# Game visual assets

The STS2 banner and character icons in this directory are game artwork served by the public OP.GG Slay the Spire 2 product pages. They remain the property of their respective rights holders and are used here only as visual identifiers for the game and its characters.

`sts1.icns` and `sts2.icns` are the official application icons bundled with the locally installed Steam game applications. They are included as visual identifiers on the local game selection screen.
